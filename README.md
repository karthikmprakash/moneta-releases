# Moneta releases

Download the desktop app for macOS, Windows, or Linux from the [latest release](../../releases/latest).

This repository only hosts build artifacts and the update metadata (`latest*.yml`) that
Moneta's built-in updater reads. The application source lives in a private repository.

- macOS: `Moneta-<version>-arm64.dmg` (Apple Silicon) or `Moneta-<version>.dmg` (Intel)
- Windows: `Moneta.Setup.<version>.exe`
- Linux: `Moneta-<version>.AppImage`

Installs update themselves from here once a new release is published.
